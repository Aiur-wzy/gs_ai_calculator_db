# 数据库维护

数据库构建、迁移和发行校验代码在[应用主仓](https://github.com/Aiur-wzy/gs_ai_calculator)。本文件是公开维护说明；主仓的[构建指南](https://github.com/Aiur-wzy/gs_ai_calculator/blob/main/docs/build.md)列出所需输入。每次更新根据已接受的旧版本整理增量，保留适用的人工和共建知识，再生成经验证的完整发行。说明来源、变更内容、兼容组合及需要重新核对的条目。

请将数据库归档及完整性清单附加到[数据库发行页](https://github.com/Aiur-wzy/gs_ai_calculator_db/releases)。仓库 Git 历史保存来源、结构、知识和版本记录。应用更新所依赖的兼容索引由应用发布渠道提供。

更新来源可以是上游变更，也可以是已整理的角色附录或共建知识。先说明具体来源和内容并取得批准，再构建完整新版本；不能在用户正在使用的既有版本上随时修补。实体上线状态按版本维护新增、变化和待核记录，知识条目的核查状态与实体上线状态分别保存。

App 和数据库可以独立发版，未变更的一侧沿用原版本。安装和更新以签名索引所列的实际验证组合为准。首个正式组合是 App 0.46.0-r19 与 db-7.2.50-r6。r6 使用 r5 的 SQLite 字节及资料来源，并以独立的正式版清单记录渠道和时间。
