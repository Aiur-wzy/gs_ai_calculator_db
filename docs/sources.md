# 数据来源

基础数据整理自 [YuanShenResources](https://gitlab.com/GuraFoundation/YuanShenResources)。各版附带发行清单，记录固定提交、游戏版本、上游更新时间、规范化版本与数据摘要。具体提交以实际发行文件为准。

正式 r6 沿用 r5 的 `CNCBWin7.2.50` 上游快照，固定提交 `f11cf545a7eee32a29999f960ebfba305f896ed3`。上游记录时间为 `2026-11-04T12:47:50-03:00`。项目资料变更在 2026-11-14 完成。发行清单分别记录上游时间与项目发行时间。

应用使用结构化角色、装备和面板资料。进阶机制的上游字段及人工或社区补充知识保留来源与适用范围，供 Agent 查证并按当前方案整理为引擎输入。来源缺失和判断待核应在资料中保留记录。

实体上线标注和角色附录包含项目核查及补充资料，不全部来自上游仓。相关分类、条目依据与待核状态随数据库保存。来源声明不等于保证每条机制已经完整或与当前正式服完全相同。
