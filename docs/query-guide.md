# 查询游戏资料

先在 App 或 CLI 核对当前数据库发行身份，再查询角色、武器或圣遗物套装。角色附录按角色读取，武器附录按武器读取。上游运行配置原文可用于检查字段来源、关联和可用证据，角色专属机制需要按场景整理为引擎输入。

当前首选 CLI，推荐 GPT-6.1 Sol 或能力更强的模型。原生 Agent 与 DeepSeek 的复杂任务表现尚不稳定；GUI 主要用于查看方案和人工审核。外部 Agent 应根据实体状态取得未上线／未知资料的使用确认，不能把 `release` 查询线当成上线证明。

可从[应用仓](https://github.com/Aiur-wzy/gs_ai_calculator)查阅随版本发布的拉表 Skill 和查询说明。发现缺失或冲突时，请记录涉及的实体 ID、资料版本、具体条目和可验证来源。
