# 数据来源与声明

原神拉表是非官方学习和研究工具，与游戏开发商及发行商无隶属关系。游戏名称、角色、图像及相关内容的权利属于各自权利人。

基础游戏资料来自版本清单列明的上游公开数据仓。项目人工和社区补充资料单独记录来源。数据库可能包含尚未上线、测试、废弃或状态未知的配置。配置出现于数据库不证明其已上线，数值也可能与当前正式服有差异。资料及计算仅供学习、研究和参考。

上线状态按角色、武器、圣遗物套装等实体记录。r6 沿用 r5 的530个实体状态：446个已上线、2个明确未上线、82个未知。使用未上线或未知实体前均需确认。该状态不为每个技能、效果、数值或附录另设标签。

原生 Agent 和支持任务确认的入口会在采用未上线或未知实体前请求确认；独立 CLI 的公开查询也会返回状态，调用它的外部 Agent 应遵从随版 Skill，向用户说明并取得确认。不能把数据库的默认查询线名 `release` 当成正式服已上线的证明。

计算结果中的机制假设和近似应结合实际场景审阅。引擎通过校验不证明输入已覆盖全部游戏机制，换用更强的模型也不免除这项检查。

基础资料来源为 [YuanShenResources](https://gitlab.com/GuraFoundation/YuanShenResources)。完整的版本信息、兼容范围和内容变更见[数据库仓](https://github.com/Aiur-wzy/gs_ai_calculator_db)。
